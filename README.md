# 📧 Spam Email Detection using Machine Learning
##📌 Project Overview
This project focuses on building a spam email detection system using machine learning techniques. The goal is to classify emails as Spam or Ham (not spam) by applying text preprocessing, feature engineering, and classification algorithms.
##⚙️ Features
1.Text preprocessing: stopword removal, tokenization, cleaning
2.Feature extraction: word count, character count, stopwords count, etc.
3.Model evaluation using accuracy, precision, recall, F1-score, and confusion matrix
4.Visualization of results for better insights
## 🛠️ Tech Stack
1.Python
2.Pandas, NumPy (data handling)
3.Scikit-learn (model building & evaluation)
4.Matplotlib, Seaborn (visualizations)
